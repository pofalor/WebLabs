# WebLabs

Лабораторные работы по курсу **«Технологии Веб-программирования»**.

Репозиторий содержит восемь лабораторных работ — от базовой вёрстки на чистом
HTML до полноценного клиент-серверного приложения на Node.js/Express с хранением
данных в базе MySQL. Каждая работа лежит в отдельной папке `laba_N`.

## Стек технологий

HTML5 · CSS3 (Flexbox) · JavaScript (ES5/ES6) · jQuery · AJAX · Node.js ·
Express · Pug · EJS · MySQL · Sequelize (ORM).

## Содержание лабораторных работ

| № | Тема | Что изучается | Как сделано |
|---|------|---------------|-------------|
| 1 | Базовый HTML | Семантические теги, структура документа | Персональный сайт из нескольких страниц |
| 2 | CSS-вёрстка | Стили, макет страницы | Тот же сайт с внешним `style.css` и Flexbox |
| 3 | Введение в JavaScript | `prompt/confirm/alert`, `document.write()`, алгоритмы | Ввод ФИО, надпись из таблицы, числовые задачи |
| 4 | Работа с датами и числами | Объект `Date`, обработка ввода, валидация | Календарные и математические вычисления |
| 5 | Графика и алгоритмы на JS | Рисование на странице, URL-параметры, генерация данных | График функции и определение покерного флеша |
| 6 | jQuery и AJAX | DOM через jQuery, загрузка JSON, вкладки | To-Do приложение и каталог услуг салона |
| 7 | Node.js + Express (REST API) | HTTP-сервер, REST, статика | CRUD-сервер и API салона в памяти |
| 8 | Express + база данных | ORM, шаблонизаторы, CRUD в БД | To-Do и салон с хранением в MySQL |

## Лабораторная работа №1 — Базовый HTML

**Изучается:** структура HTML-документа, семантические и текстовые теги
(`<h1>–<h6>`, `<blockquote>`, `<table>`, `<img>`, `<a>`, `<ul>` и др.),
двухколоночный макет средствами тегов.

**Как сделано:** статический персональный сайт из связанных страниц —
`index.html` (главная), `about.html`, `hobbies.html`, `education.html`,
`contacts.html`. Навигация между страницами реализована обычными ссылками,
оформление — только средствами HTML.

## Лабораторная работа №2 — CSS-вёрстка

**Изучается:** отделение оформления от содержания, внешние таблицы стилей,
блочная модель, макет с помощью Flexbox (`header` / `nav` / `main`).

**Как сделано:** тот же сайт, что и в ЛР №1, переведён на внешний файл
`style.css`. Страницы получили общий каркас: шапку, боковое меню и
контентную область, свёрстанную через `display: flex`.

## Лабораторная работа №3 — Введение в JavaScript

**Изучается:** диалог с пользователем (`prompt`, `confirm`, `alert`),
метод `document.write()`, базовые алгоритмы обработки чисел.

**Как сделано:** страница-меню `index.html` со ссылками на задачи:
- **Задача 1** — запрос ФИО, подтверждение корректности ввода и вывод
  приветствия либо сообщения об ошибке (с защитой от пустого ввода).
- **Задача 2** (`task2.html`) — надпись «ИКТЗИ», построенная из закрашенных
  ячеек таблицы; каждая буква задана матрицей `0/1`.
- **Задача 3** (`task3.html`) — числовые задачи: поиск наибольшего `M > 1`,
  на которое делится сумма цифр числа `N`, и подсчёт количества минимальных
  цифр в записи числа.

## Лабораторная работа №4 — Даты и числа

**Изучается:** объект `Date`, вычисления с датами, валидация
пользовательского ввода.

**Как сделано:** одна страница `laba.html` с несколькими блоками: вывод
текущей даты и дня недели, подсчёт числа дней до сессии, ввод и проверка
памятной даты, вычисление суммы последовательности `(n-2)²` и подсчёт нулей
в младших разрядах числа. Для каждого блока написаны отдельные функции с
проверкой корректности данных.

## Лабораторная работа №5 — Графика и алгоритмы

**Изучается:** программное рисование на странице, чтение параметров из URL,
генерация случайных данных и их анализ.

**Как сделано:** страница `laba_5.html` в две колонки:
- **График функции** `2 − x³` — координатная сетка и оси строятся
  позиционированными элементами; границы отображения можно передать через
  параметры URL.
- **Покер** — генерируется случайная «рука» из карт, карты отображаются
  визуально, а функция `isFlush()` определяет, собран ли флеш (все карты
  одной масти).

## Лабораторная работа №6 — jQuery и AJAX

**Изучается:** работа с DOM через jQuery, загрузка данных из JSON,
переключение вкладок, группировка данных.

**Как сделано:** три подпроекта, данные подгружаются из `*.json`:
- **`ex1`** — список задач (To-Do) с вкладками «Новые», «Старые», «Теги»;
  задачи группируются по тегам средствами JavaScript.
- **`ex2`** — расширение `ex1`: добавлена вкладка «Добавить» с формой ввода
  новой задачи.
- **`salon`** — каталог услуг парикмахерской (`services.json`) с
  группировкой по категориям и по мастерам.

## Лабораторная работа №7 — Node.js + Express (REST API)

**Изучается:** создание HTTP-сервера на Express, REST-архитектура
(GET/POST/PUT/DELETE), раздача статических файлов.

**Как сделано:**
- **`ex1`** — учебный CRUD-сервер для сущности «пользователи»: данные хранятся
  в массиве в памяти, клиент в папке `public`.
- **`salon`** — сервер салона парикмахерской: REST API для получения всех
  услуг, добавления новой, а также выборки по категории и по мастеру. Клиент
  вынесен в папку `client`.

Запуск: `npm install`, затем `node server.js` (или `npm start`), сервер
слушает порт `3000`.

## Лабораторная работа №8 — Express + база данных

**Изучается:** хранение данных в MySQL, работа с БД напрямую и через ORM,
серверные шаблонизаторы (EJS, Pug), полный CRUD с редактированием.

**Как сделано:** три подпроекта с клиент-серверной архитектурой:
- **`ex1`** — To-Do приложение, обращающееся к MySQL через драйвер `mysql2`
  напрямую (SQL-запросы); форма редактирования рендерится шаблоном **EJS**.
- **`ex2`** — то же приложение, переписанное на ORM **Sequelize** (модель
  `Task`), форма редактирования на шаблонизаторе **Pug**.
- **`salon`** — салон парикмахерской на Sequelize с моделью `Service`,
  переопределением HTTP-методов через `method-override` и конфигурацией БД
  из `.env` (`dotenv`).

Запуск: настроить подключение к MySQL (имя БД, пользователь, пароль в
`server.js` или `.env`), выполнить `npm install` и `node server.js`.
